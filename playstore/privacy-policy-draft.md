# Kebijakan Privasi Monopoli Indonesia

Tanggal berlaku: [isi tanggal publikasi]

Monopoli Indonesia menggunakan layanan pihak ketiga untuk menjalankan fitur
multiplayer, autentikasi, analitik, pelaporan error, dan iklan.

Layanan yang digunakan dapat mencakup:

- Firebase Authentication
- Firebase Realtime Database
- Cloud Firestore
- Firebase Analytics
- Firebase Crashlytics
- Google Mobile Ads

Data yang diproses dapat meliputi identitas pemain yang dibuat aplikasi, nama
pemain, data room dan permainan, informasi perangkat, interaksi penggunaan,
diagnostik crash, serta data iklan sesuai konfigurasi layanan Google.

Data digunakan untuk menyediakan permainan multiplayer, menyimpan profil,
meningkatkan kualitas aplikasi, mendiagnosis masalah, mencegah penyalahgunaan,
dan menampilkan iklan.

Pengguna dapat meminta pertanyaan atau penghapusan data melalui:

- Email: [isi email dukungan]
- Situs: [isi URL dukungan]
